HC Pizza

A simple pizza ordering POC built using React Native and Expo.

Features

- Pizza menu
- All, Veg and Popular categories
- Add to cart
- Increase and decrease quantity
- Remove pizza from cart
- Cart total
- Place order flow

Tech Used

- React Native
- Expo
- TypeScript
- Expo Router
- React Context API

Run the Project

npm install
npx expo start

About

This is a practical POC created to understand the basic flow of a pizza ordering mobile application.
